# Course pages

Interactive handouts (Muddiest Point study guides, walkthroughs) for Milad Roohi's UNL courses, served with GitHub Pages and embedded in Canvas.
Canvas strips scripts from its own pages and files, so interactive pages (Plotly, KaTeX) are hosted here and shown on Canvas in a frame.

Layout: `<course>/<year>/<slug>/index.html`. Publish with `tools/publish.py` (see its header).
Student work and verbatim student comments are never posted here.
