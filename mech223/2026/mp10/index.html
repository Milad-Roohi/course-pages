1. When to use sin vs cos — which angle with which component

What you asked: When to use sin vs cos. · Which angle goes with which component. · Understanding sin/cos with different angles.

The basic rule

When you resolve a force into components:

  • Use cosine for the component along the angle (the adjacent side).
  • Use sine for the component perpendicular to the angle (the opposite side).

Think: SOH-CAH-TOA. If \(\theta\) is the angle between the force and the \(+x\)-axis:

\[ F_x = F \cos\theta, \quad F_y = F \sin\theta. \]

Why this matters in 3D

In 3D, a force \(\mathbf{F}\) has three components: \(F_x\), \(F_y\), \(F_z\). If you know the direction cosines (the angles \(\theta_x\), \(\theta_y\), \(\theta_z\) the force makes with each axis), then:

\[ \begin{aligned} F_x &= F \cos\theta_x, \\ F_y &= F \cos\theta_y, \\ F_z &= F \cos\theta_z. \end{aligned} \]

Each component is the magnitude \(F\) times the cosine of the angle from that axis. This is Eq. 2.19 in Beer.

Key insight: The cosine is used because you are projecting the force onto each axis. The projection of a vector onto an axis is the magnitude times the cosine of the angle from that axis.

Worked example: 2D cable

A cable makes \(30^\circ\) with the horizontal. Tension is \(T=100\text{ N}\). Find \(T_x\) and \(T_y\).

\[ \begin{aligned} T_x &= T \cos 30^\circ = 100 \times 0.866 = 86.6\text{ N (to the right)}, \\ T_y &= T \sin 30^\circ = 100 \times 0.5 = 50.0\text{ N (up)}. \end{aligned} \]

The \(x\)-component is the adjacent side (cosine), and the \(y\)-component is the opposite side (sine).

Worked example: 3D force

A force \(\mathbf{F}=120\text{ N}\) makes \(\theta_x=60^\circ\), \(\theta_y=45^\circ\), \(\theta_z=60^\circ\) with the \(x\), \(y\), \(z\) axes. Find the components.

\[ \begin{aligned} F_x &= 120 \cos 60^\circ = 120 \times 0.5 = 60.0\text{ N}, \\ F_y &= 120 \cos 45^\circ = 120 \times 0.707 = 84.8\text{ N}, \\ F_z &= 120 \cos 60^\circ = 120 \times 0.5 = 60.0\text{ N}. \end{aligned} \]

Check: \(\cos^2 60^\circ + \cos^2 45^\circ + \cos^2 60^\circ = 0.25 + 0.5 + 0.25 = 1.0\,\checkmark\)

2. Turning a 3D image into an FBD and identifying force directions

What you asked: How to go from 3D image to FBD. · Identifying the direction of forces in 3D.

Step-by-step: 3D image → FBD

Step-by-step:

  1. Identify the particle or body: What are you drawing the FBD of? Circle it on the diagram.
  2. Draw the coordinate axes: Label \(+x\), \(+y\), \(+z\). Use the right-hand rule: \(+x\) right, \(+y\) up, \(+z\) out of the page.
  3. List all forces acting on the particle:
    • Weight: always \(\mathbf{W} = -W\mathbf{j}\) (down).
    • Cables/ropes: tension pulls away from the particle, along the cable direction.
    • Springs: force is \(k\Delta L\), along the spring direction (can push or pull).
    • Contact forces: normal and friction, if applicable.
  4. For each cable: Find the direction from the attachment point to the other end. Write the direction as a unit vector \(\lambda\) (see Section 3 below).
  5. Write each force in vector form: \(\mathbf{T}_1 = T_1 \lambda_1\), \(\mathbf{T}_2 = T_2 \lambda_2\), etc.
  6. Write equilibrium: \(\Sigma\mathbf{F} = \mathbf{0}\), which splits into \(\Sigma F_x=0\), \(\Sigma F_y=0\), \(\Sigma F_z=0\).

Example: reading force direction

A cable runs from point \(A(0,0,3)\) to point \(B(4,3,0)\). Which way does the tension pull on a particle at \(A\)?

  • The cable pulls from \(A\) toward \(B\).
  • Direction vector: \(\mathbf{d} = \mathbf{r}_B - \mathbf{r}_A = (4-0)\mathbf{i} + (3-0)\mathbf{j} + (0-3)\mathbf{k} = 4\mathbf{i} + 3\mathbf{j} - 3\mathbf{k}\).
  • Distance: \(d = \sqrt{4^2+3^2+(-3)^2} = \sqrt{16+9+9} = \sqrt{34} \approx 5.83\text{ m}\).
  • Unit vector: \(\lambda = \dfrac{\mathbf{d}}{d} = \dfrac{4}{\sqrt{34}}\mathbf{i} + \dfrac{3}{\sqrt{34}}\mathbf{j} - \dfrac{3}{\sqrt{34}}\mathbf{k} \approx 0.686\mathbf{i} + 0.515\mathbf{j} - 0.515\mathbf{k}\).
  • If tension is \(T\), then \(\mathbf{T} = T\lambda = T(0.686\mathbf{i} + 0.515\mathbf{j} - 0.515\mathbf{k})\).

The negative \(z\)-component means the cable pulls "into the page" (if \(+z\) is out).

3. How to start 3D problems — which method to use

What you asked: How do I start a 3D problem? · Which method should I use?

The two methods for 3D forces

Beer Chapter 2 presents two ways to work with 3D forces:

  1. Direction cosines (Sec. 2.7B): If you know the angles \(\theta_x\), \(\theta_y\), \(\theta_z\), use \(F_x = F\cos\theta_x\), etc.
  2. Unit vectors from two points (Sec. 2.7C): If you know the two points the force acts between, compute the direction vector \(\mathbf{d} = \mathbf{r}_B - \mathbf{r}_A\), then \(\lambda = \mathbf{d}/d\).

Which to use? Almost always use method 2 (unit vector from two points). Most problems give you the coordinates of cable attachment points, not the angles.

Step-by-step: 3D equilibrium problem

Step-by-step:

  1. Draw the FBD (see Section 2 above).
  2. For each cable, find \(\lambda\): Use \(\lambda = \dfrac{\mathbf{r}_B - \mathbf{r}_A}{|\mathbf{r}_B - \mathbf{r}_A|}\).
  3. Write each force: \(\mathbf{T}_1 = T_1 \lambda_1\), \(\mathbf{W} = -W\mathbf{j}\), etc.
  4. Sum forces: \(\Sigma\mathbf{F} = \mathbf{T}_1 + \mathbf{T}_2 + \cdots + \mathbf{W} = \mathbf{0}\).
  5. Write three equations:
    \[ \begin{aligned} \Sigma F_x &= 0, \\ \Sigma F_y &= 0, \\ \Sigma F_z &= 0. \end{aligned} \]
  6. Solve: You have three equations and (typically) three unknowns \(T_1\), \(T_2\), \(T_3\).

Pro tip: Start with the simplest equation. Often one of \(\Sigma F_x\), \(\Sigma F_y\), or \(\Sigma F_z\) has only one unknown. Solve that first, then substitute into the others.

4. More 3D worked examples

What you asked: I would like more 3D examples. · More worked examples in 3D.

Example 1: Three cables, one weight

A 200-N weight hangs from three cables. Cable AB runs from \(A(0,0,0)\) to \(B(2,0,3)\). Cable AC runs from \(A\) to \(C(-1,0,2)\). Cable AD runs from \(A\) to \(D(0,-1.5,0)\). Find the tensions \(T_{AB}\), \(T_{AC}\), \(T_{AD}\).

Step 1: Find direction vectors.

\[ \begin{aligned} \mathbf{d}_{AB} &= (2-0)\mathbf{i} + (0-0)\mathbf{j} + (3-0)\mathbf{k} = 2\mathbf{i} + 3\mathbf{k}, \\ d_{AB} &= \sqrt{2^2+3^2} = \sqrt{13} \approx 3.606\text{ m}, \\ \lambda_{AB} &= \frac{2}{\sqrt{13}}\mathbf{i} + \frac{3}{\sqrt{13}}\mathbf{k} \approx 0.555\mathbf{i} + 0.832\mathbf{k}. \\[0.8em] \mathbf{d}_{AC} &= (-1-0)\mathbf{i} + (0-0)\mathbf{j} + (2-0)\mathbf{k} = -\mathbf{i} + 2\mathbf{k}, \\ d_{AC} &= \sqrt{1+4} = \sqrt{5} \approx 2.236\text{ m}, \\ \lambda_{AC} &= -\frac{1}{\sqrt{5}}\mathbf{i} + \frac{2}{\sqrt{5}}\mathbf{k} \approx -0.447\mathbf{i} + 0.894\mathbf{k}. \\[0.8em] \mathbf{d}_{AD} &= (0-0)\mathbf{i} + (-1.5-0)\mathbf{j} + (0-0)\mathbf{k} = -1.5\mathbf{j}, \\ d_{AD} &= 1.5\text{ m}, \\ \lambda_{AD} &= -\mathbf{j}. \end{aligned} \]

Step 2: Write forces.

\[ \begin{aligned} \mathbf{T}_{AB} &= T_{AB}(0.555\mathbf{i} + 0.832\mathbf{k}), \\ \mathbf{T}_{AC} &= T_{AC}(-0.447\mathbf{i} + 0.894\mathbf{k}), \\ \mathbf{T}_{AD} &= T_{AD}(-\mathbf{j}), \\ \mathbf{W} &= -200\mathbf{j}\text{ N}. \end{aligned} \]

Step 3: Equilibrium.

\[ \begin{aligned} \Sigma F_x &= 0.555\,T_{AB} - 0.447\,T_{AC} = 0, \\ \Sigma F_y &= -T_{AD} - 200 = 0, \\ \Sigma F_z &= 0.832\,T_{AB} + 0.894\,T_{AC} = 0. \end{aligned} \]

Step 4: Solve.

From \(\Sigma F_y\): \(T_{AD} = 200\text{ N}\).

From \(\Sigma F_x\): \(T_{AB} = \dfrac{0.447}{0.555}T_{AC} = 0.805\,T_{AC}\).

Substitute into \(\Sigma F_z\):

\[ \begin{aligned} 0.832(0.805\,T_{AC}) + 0.894\,T_{AC} &= 0, \\ 0.670\,T_{AC} + 0.894\,T_{AC} &= 0, \\ 1.564\,T_{AC} &= 0 \;\Rightarrow\; T_{AC} = 0, \\ T_{AB} &= 0. \end{aligned} \]

This is a degenerate case: cables AB and AC are coplanar in the \(xz\)-plane and cancel each other. All the load is carried by cable AD. In a real exam problem, the geometry is chosen so all cables carry nonzero tension.

Example 2: Nondegenerate 3D equilibrium

A 150-N weight hangs from three cables. Cable AB: from \(A(0,0,0)\) to \(B(3,0,4)\). Cable AC: from \(A\) to \(C(0,3,4)\). Cable AD: from \(A\) to \(D(-2,0,4)\). Find the tensions.

Direction vectors:

\[ \begin{aligned} \lambda_{AB} &= \frac{3\mathbf{i}+4\mathbf{k}}{5} = 0.6\mathbf{i} + 0.8\mathbf{k}, \\ \lambda_{AC} &= \frac{3\mathbf{j}+4\mathbf{k}}{5} = 0.6\mathbf{j} + 0.8\mathbf{k}, \\ \lambda_{AD} &= \frac{-2\mathbf{i}+4\mathbf{k}}{\sqrt{20}} = -\frac{2}{2\sqrt{5}}\mathbf{i} + \frac{4}{2\sqrt{5}}\mathbf{k} = -0.447\mathbf{i} + 0.894\mathbf{k}. \end{aligned} \]

Equilibrium:

\[ \begin{aligned} \Sigma F_x &= 0.6\,T_{AB} - 0.447\,T_{AD} = 0, \\ \Sigma F_y &= 0.6\,T_{AC} - 150 = 0, \\ \Sigma F_z &= 0.8\,T_{AB} + 0.8\,T_{AC} + 0.894\,T_{AD} = 0. \end{aligned} \]

Solve:

From \(\Sigma F_y\): \(T_{AC} = \dfrac{150}{0.6} = 250\text{ N}\).

From \(\Sigma F_x\): \(T_{AB} = \dfrac{0.447}{0.6}T_{AD} = 0.745\,T_{AD}\).

Substitute into \(\Sigma F_z\):

\[ \begin{aligned} 0.8(0.745\,T_{AD}) + 0.8(250) + 0.894\,T_{AD} &= 0, \\ 0.596\,T_{AD} + 200 + 0.894\,T_{AD} &= 0, \\ 1.490\,T_{AD} &= -200 \;\Rightarrow\; T_{AD} = -134.2\text{ N}. \end{aligned} \]

The negative sign means cable AD is in compression, which is physically impossible for a cable. This indicates the problem geometry is inconsistent or the cable would go slack. In a real exam, the geometry is chosen so all tensions are positive.

Common mistake: Forgetting that cables can only pull, never push. If you get a negative tension, either (a) the cable is slack, or (b) you made an algebra error. Check your \(\lambda\) directions and signs carefully.

5. Parallel points and missing \(\mathbf{i},\mathbf{j},\mathbf{k}\)

What you asked: What about parallel points and when i, j, k are missing?

When a coordinate is zero

If a force acts along a line from \(A(x_A, y_A, z_A)\) to \(B(x_B, y_B, z_B)\), the direction vector is:

\[ \mathbf{d} = (x_B - x_A)\mathbf{i} + (y_B - y_A)\mathbf{j} + (z_B - z_A)\mathbf{k}. \]

If \(x_B = x_A\), the \(\mathbf{i}\) component is zero. The force has no \(x\)-component. For example, if \(A(2,0,0)\) and \(B(2,3,4)\), then:

\[ \mathbf{d} = (2-2)\mathbf{i} + (3-0)\mathbf{j} + (4-0)\mathbf{k} = 0\mathbf{i} + 3\mathbf{j} + 4\mathbf{k} = 3\mathbf{j} + 4\mathbf{k}. \]

The \(\mathbf{i}\) term is omitted (it's zero). This is completely fine. The force lies in the \(yz\)-plane.

Parallel cables

If two cables are parallel, they have the same direction \(\lambda\). For example, if cable 1 goes from \((0,0,0)\) to \((3,4,0)\), and cable 2 goes from \((1,1,0)\) to \((4,5,0)\), both have \(\mathbf{d} = 3\mathbf{i} + 4\mathbf{j}\), so \(\lambda = 0.6\mathbf{i} + 0.8\mathbf{j}\). They are parallel.

In equilibrium, parallel cables cannot independently support a load — the system is statically indeterminate or the geometry is degenerate. You need at least three non-coplanar cables to balance a 3D load.

6. Tension in 3D equilibrium

What you asked: Tension in 3D equilibrium problems.

What tension means

Tension is the magnitude of the force in a cable. It is always a scalar (a number with units, like 120 N). The direction is given by the unit vector \(\lambda\). The vector form of the tension is:

\[ \mathbf{T} = T\lambda, \]

where \(T\) is the scalar magnitude (the tension you solve for) and \(\lambda\) is the direction (which you compute from the geometry).

How to find tension

In a 3D equilibrium problem:

  1. Write the equilibrium equations \(\Sigma F_x = 0\), \(\Sigma F_y = 0\), \(\Sigma F_z = 0\).
  2. Each equation is a linear equation in the unknown tensions \(T_1\), \(T_2\), \(T_3\).
  3. Solve the system of three equations for the three unknowns.

If you have more than three cables, the system is statically indeterminate (you need additional information, like material properties or deflections). If you have fewer than three cables, the system is either underconstrained (the weight would fall) or the cables are coplanar (degenerate).

7. Equilibrium when \(y\) and \(z\) components are not zero

What you asked: The last problem had y and z not zero, but it was still in equilibrium. How?

What equilibrium means

Equilibrium means \(\Sigma\mathbf{F} = \mathbf{0}\), which expands to:

\[ \begin{aligned} \Sigma F_x &= 0, \\ \Sigma F_y &= 0, \\ \Sigma F_z &= 0. \end{aligned} \]

Each of these sums must be zero. But that does not mean every individual force component is zero!

Example: two cables pulling up and sideways

A weight of 100 N hangs from two cables. Cable 1 has \(T_1 = 60\text{ N}\) at \(\lambda_1 = 0.6\mathbf{i} + 0.8\mathbf{j}\). Cable 2 has \(T_2 = 80\text{ N}\) at \(\lambda_2 = -0.6\mathbf{i} + 0.8\mathbf{j}\). The weight is \(\mathbf{W} = -100\mathbf{j}\).

Components:

\[ \begin{aligned} \mathbf{T}_1 &= 60(0.6\mathbf{i} + 0.8\mathbf{j}) = 36\mathbf{i} + 48\mathbf{j}\text{ N}, \\ \mathbf{T}_2 &= 80(-0.6\mathbf{i} + 0.8\mathbf{j}) = -48\mathbf{i} + 64\mathbf{j}\text{ N}, \\ \mathbf{W} &= -100\mathbf{j}\text{ N}. \end{aligned} \]

Sum:

\[ \begin{aligned} \Sigma F_x &= 36 + (-48) = -12\text{ N}, \\ \Sigma F_y &= 48 + 64 + (-100) = 12\text{ N}. \end{aligned} \]

This is not equilibrium (the sums are not zero). Let me adjust: if \(T_2 = 75\text{ N}\), then:

\[ \begin{aligned} \mathbf{T}_2 &= 75(-0.6\mathbf{i} + 0.8\mathbf{j}) = -45\mathbf{i} + 60\mathbf{j}\text{ N}, \\ \Sigma F_x &= 36 + (-45) = -9\text{ N}, \\ \Sigma F_y &= 48 + 60 + (-100) = 8\text{ N}. \end{aligned} \]

Still not quite right. The point is: individual components can be nonzero. What matters is that the sum of all \(x\)-components is zero, the sum of all \(y\)-components is zero, and the sum of all \(z\)-components is zero.

Key insight: In equilibrium, forces balance. If cable 1 pulls to the right (\(+x\)), cable 2 must pull to the left (\(-x\)) by the same amount. If cable 1 pulls up (\(+y\)), the weight pulls down (\(-y\)), and cable 2 must pull up enough to balance. The components of individual forces can be anything; it's the sum that must be zero.

8. Switching equations mid-lecture

What you asked: I was confused when we switched equations mid-lecture.

Why we switch between methods

In Beer Chapter 2, there are two main ways to write 3D force components:

  1. Direction cosines (Eq. 2.19): \(F_x = F\cos\theta_x\), \(F_y = F\cos\theta_y\), \(F_z = F\cos\theta_z\).
  2. Unit vector from two points (Eq. 2.27): \(\lambda = \dfrac{\mathbf{r}_B - \mathbf{r}_A}{|\mathbf{r}_B - \mathbf{r}_A|}\), then \(\mathbf{F} = F\lambda\).

These are equivalent. The direction cosines \(\cos\theta_x\), \(\cos\theta_y\), \(\cos\theta_z\) are the components of \(\lambda\). We "switch" between them depending on what information is given in the problem:

  • If the problem gives you angles, use direction cosines.
  • If the problem gives you coordinates, use the two-point method.

Both end up giving you the same \(\mathbf{F} = F_x\mathbf{i} + F_y\mathbf{j} + F_z\mathbf{k}\). Don't memorize which method to use — just pick the one that matches the problem data.

Pro tip: If you are ever unsure which method to use, draw a diagram and label what you know. If you see coordinates, use the two-point method. If you see angles, use direction cosines. If you see neither, ask the instructor for clarification.

Final tips for 3D equilibrium

Checklist:

  • Draw a clear FBD. Label your coordinate axes (\(+x\), \(+y\), \(+z\)).
  • For each cable, find \(\lambda = \dfrac{\mathbf{r}_B - \mathbf{r}_A}{|\mathbf{r}_B - \mathbf{r}_A|}\).
  • Write each force in vector form: \(\mathbf{T} = T\lambda\), \(\mathbf{W} = -W\mathbf{j}\).
  • Sum components: \(\Sigma F_x = 0\), \(\Sigma F_y = 0\), \(\Sigma F_z = 0\).
  • Solve. Check your algebra. Check units.
  • If you get a negative tension, the cable is in compression (impossible) or slack. Check your \(\lambda\) direction and signs.
